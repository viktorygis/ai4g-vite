## 🎯 Что делаем

### ✅ Обязательно
1. **Цвета → переменные** (не меняя визуал)
2. **БЭМ-комментарии** для каждого элемента
3. **Стандартные breakpoints** из переменных
4. **Структура секций** с комментариями
5. **Импорт `sass:color`**

### ❌ Не делаем
- Не меняем визуал
- Не удаляем классы
- Не трогаем HTML

Шаг 4: БЭМ-комментарии
Формат:

SCSS
.card {
  //.card__header
  &__header { }

  //.card__title
  &__title { }

  //.card__content
  &__content {
    // Для вложенных тегов комментарий НЕ нужен
    img {
      width: 100%;
    }
  }

  //.card__button
  &__button {
    &:hover { }

    //.card__button--primary
    &--primary { }
  }
}
Правила:

Один комментарий = один элемент
Формат: //.block__element
Для модификаторов: //.block__element--modifier
Для тегов (img, a, span) — без комментария
Шаг 5: Breakpoints
Стандартные:

SCSS
$breakpoint-xl: 1200px;  // Extra large
$breakpoint-lg: 992px;   // Large
$breakpoint-md: 768px;   // Medium
$breakpoint-sm: 576px;   // Small
Использование:

SCSS
// ❌ Было:
@media (max-width: 768px) { }

// ✅ Стало:
@include respond-to($breakpoint-md) { }
Когда оставить кастомный breakpoint:

Специфичные дизайн-требования (840px, 1120px)
Уникальные точки перелома
Если стандартный ломает визуал
