# AI4G Vite

Многостраничный сайт с упражнениями и техниками.
В проекте используются HTML, PHP, CSS, JavaScript.

## Быстрый старт

```bash
npm install
npm run dev

```

5. Откройте браузер и перейдите по адресу `http://localhost:3000` (или по адресу, который Vite выведет в терминале).

## Структура проекта

```
/
├── index.html                  # Главная страница
├── patterns.html, allegro.html, vozmozhnosti.html  # Основные разделы
├── technics/                   # Папка с техниками (html)
│   ├── vzmah.html
│   ├── muzey-ubezhdeniy.html
│   ├── ... (и др)
├── img/                        # Картинки, графика
├── css/ или styles/            # Основные стили (если есть; возможно в корне или в каждой html)
├── js/                         # JS-скрипты (если есть)
├── vendor/, php/               # PHP и сторонние зависимости (если проект используется на сервере)
├── ... другие вспомогательные файлы
```

- Почти все страницы используют **внешние библиотеки по CDN**: jQuery, Fancybox, Swiper и другие.
- Основная часть разметки — HTML, присутствует немного PHP.

## Как разворачивать

1. **Для статического сайта:**
   Просто открывайте `index.html` или выкладывайте на любой хостинг.
2. **Если нужен сервер и используется PHP:**
   Заливать на сервер с поддержкой PHP, файлы \*.php будут обрабатываться сервером.

## План поэтапного перехода на Vite

1. **Собрать все стили и js в одну структуру** (желат��льно отделить vendor и свои файлы).
2. **Перенести все стили (CSS/SCSS) в папку src/styles/**
3. **Код JavaScript вынести в отдельные модули, импортировать централизовано**
4. **Статические файлы (img, fonts) оставить в public или src/assets**
5. **Для страниц (html) использовать или шаблонизатор (например, ejs, nunjucks) или оставить чистый HTML для MPA**
6. **PHP-файлы вынести отдельно, если потребуется только фронтенд — удалить**

## Что можно удалить

- **Лишние и неиспользуемые картинки и иконки**
- **Фрагменты (стили, js, html), которые не подключаются ни к одной странице**
- **В папках `technics/`, `img/`, `css/`, `js/`: удалить дублирующийся, невостребованный и временный код**
- **Все ключи, токены, пароли (если есть в коде или в конфигах — обязательно удалить)**
- **Фрагменты PHP, если нужен только фронтенд**

---

## Советы по подготовке проекта под Vite

- Все SCSS/CSS импортировать в один основной файл и подключать в main.js (пример: `import './styles/main.scss'`)
- Все свои JS (без CDN-библиотек) — модульно в `src/scripts/`; все импорты тоже через главный js-файл.
- Страницы класть в `src/`, использовать Multi-Page Application настройку для Vite как в [vite-mpa-setup](https://vitejs.dev/guide/build.html#multi-page-app)
- Все используемые картинки, шрифты и т.д. — в папку `public/` или через импорт, чтобы Vite умел их собирать и оптимизировать.
- Подключение CDN-библиотек оставить через
  ```html
  <script src="https://..."></script>
  ```
  либо установить как npm-зависимости (лучше!) и импортировать через js.
- Если будет нужна только статика — можно вообще полностью удалить `.php`, оставить только html + ассеты.

## Пример команды для первоначального рефакторинга

```sh
# Создай новую структуру src/ и перенеси туда код по MPA модели:
mkdir -p src/styles src/scripts src/assets src/pages
# src/pages — все html
# src/styles — scss, css
# src/scripts — js
# src/assets — img, fonts
```
